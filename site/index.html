How to use a baseline

From library to tenant in three steps.

Review

Read the description and rationale of each setting and check it against your own requirements.

Download

Grab the baseline as .json from GitHub — versioned, with a changelog.

Implement

Build it in the Intune Settings Catalog and test on a pilot group before rolling out.

Baselines are provided as guidance. Always validate framework mappings and test settings in your own environment before deploying to production.
